# Rate My Professors Scraper API – code examples

Examples for every Rate My Professors endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/professor.sh`](curl/professor.sh) | `bash professor.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/professor.php`](php/professor.php) | `php professor.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Professor.cs`](csharp/Professor.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/professor.go`](go/professor.go) | `go run professor.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/ProfessorExample.java`](java/ProfessorExample.java) | `java ProfessorExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/professor.rb`](ruby/professor.rb) | `ruby professor.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/professor.mjs`](nodejs/professor.mjs) | `node professor.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
